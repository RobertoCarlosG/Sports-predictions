Always use `pnpm` instead of `npm` for frontend commands in this project.

**Why:** User preference — project uses pnpm as the package manager.

**How to apply:** Replace `npm run build`, `npm test`, `npm ci`, etc. with `pnpm run build`, `pnpm test`, `pnpm install`, etc. in the frontend directory.
